# 과학탐구 프로젝트 워크시트 (온라인 팀 공동 작성판)

- index.html : 학생용. 반 + 팀 이름 + 팀 비밀번호로 들어가 팀원끼리 함께 쓰고 자동 저장함. '이번 주 제출' 버튼으로 주간 기록을 남김.
- teacher.html : 교사용. 교사 열쇠를 넣으면 모든 반·팀의 진행률, 주별 제출, 워크시트·제출본, 첨부, 비밀번호 재설정, CSV를 봄.
- 서버 : Supabase 프로젝트 science-project-tracker (xiyzesbtxrpkistruaii). 교사 열쇠는 파일에 들어 있지 않음.

## 올리는 법 (Netlify Drop)
1. app.netlify.com/drop 에 이 폴더(index.html, teacher.html)를 통째로 끌어다 놓음.
2. 나온 주소가 학생용 주소임. 교사용은 주소 끝에 /teacher.html 을 붙임.
3. 학생에게는 학생용 주소만 알림(QR 권장). 아이패드에서 사파리로 열고 '홈 화면에 추가'하면 앱처럼 씀.

## 첫 수업 안내
- 팀장이 반·팀 이름·비밀번호를 정해 '새 팀 만들기' → 팀원은 같은 정보로 '들어가기'.
- 비밀번호를 잊으면 교사용 화면에서 팀을 눌러 새로 정함.
- 첨부: 사진은 자동 축소, 문서는 한 개 2MB·팀 전체 8MB까지. 영상은 드라이브·유튜브 링크로.

## 5+ 시뮬레이션 탭 (2026-10-26 추가)
- 파이썬 코드, HTML 코드나 .py·.html 파일을 올리면 아이패드에서도 바로 실행됨. 팀원·교사도 같은 시뮬레이션을 열어 봄.
- 카드마다 제목과 설명(무엇을·어떤 조건으로·결과의 의미·현실과 다른 점)을 씀.
- 5. 검증에서 'AI 시뮬레이션'을 고르면 검증 탭에 시뮬레이션 탭으로 가는 안내가 나오고, 그때만 진행률에 들어감.
- 코드를 고쳐 저장하면 새 판이 생기고, 주간 제출본에 쓰인 예전 판은 남음(교사가 그 주 코드로 실행 가능). 쓰이지 않는 예전 판은 자동으로 치워 팀 공간을 돌려받음.
- 한계: 끝없이 도는 HTML 코드는 화면을 멈추게 할 수 있음 → 브라우저 새로 고침. 파이썬 첫 실행은 10~30초.

## 동시 작성 개선 (2026-10-26 저녁)
- 쓰는 중에는 1초마다 팀원 내용을 받아 옴(1분 넘게 아무도 안 쓰면 3초마다). 저장은 입력을 멈추고 0.5초 뒤.
- 같은 칸을 여러 명이 동시에 써도 덮어쓰지 않고 두 글을 합침. 한글 조합 중에 팀원 글이 들어와도 지워지지 않음.
- 같은 자리에 동시에 쓰면 두 글이 이어 붙음(순서가 섞일 수는 있으나 사라지지 않음). 고르기 칸은 나중에 고른 것이 남음.
- 이 판을 올린 뒤에는 학생들이 열어 둔 예전 화면을 한 번 새로 고침하게 할 것(예전 화면은 덮어쓰기 방식임).

## ✎ 이번 주 한 일 · 3-1 알아야 할 지식 (2026-10-27 추가)
- ✎ 이번 주 한 일: 팀 정보의 조장·조원마다 칸이 생기고, 실험 시간에 각자 한 일을 한두 줄 씀. 매주 월요일 새 칸이 열리고 지난주 기록은 남음. 제출할 때 안 쓴 사람을 알려 줌. 교사 화면 목록에 '이번 주 한 일 n/m명', CSV에 각자 한 일.
- 3-1 알아야 할 지식(선행 연구): 용어 · 간단한 설명 · 어디에 필요한가 · 출처. 출처 종류(웹·기사/논문/책)를 고르고 칸을 채우면 APA 형식으로 자동 정리됨. 링크·DOI는 눌러 열림.
- 교사 화면 '팀 지우기': 팀 상세 맨 아래에서 팀 이름을 그대로 적어야 지워짐(되돌릴 수 없음).
